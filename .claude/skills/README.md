# Design Skills for Claude Code

35 skills for website design, UI/UX, motion graphics, animations, scroll effects, and 3D — curated from the top-rated GitHub skill repos of 2026. Claude Code loads these automatically when you ask for design work in this project.

## UI/UX Pro Max suite
Source: [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — the most-installed UI/UX skill (searchable database of design styles, color palettes, font pairings, and GSAP motion presets).

- `ui-ux-pro-max` — flagship design intelligence: styles, palettes, fonts, motion presets
- `design` — general design guidance
- `design-system` — design-system generation
- `ui-styling` — deep styling database
- `brand` — brand identity
- `banner-design` — banners and hero graphics
- `slides` — slide/presentation design

## Taste suite
Source: [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) — the most-starred third-party frontend design skill. Tunable via DESIGN_VARIANCE, MOTION_INTENSITY, and VISUAL_DENSITY (each 1–10); high MOTION_INTENSITY gives magnetic, scroll-triggered animations.

- `taste-skill` — main anti-generic frontend design skill
- `brutalist-skill`, `minimalist-skill`, `soft-skill` — style variants
- `redesign-skill` — redesign existing UIs
- `output-skill` — output quality control
- `image-to-code-skill`, `stitch-skill` — turn designs/images into code
- `brandkit` — brand kit generation
- `imagegen-frontend-web`, `imagegen-frontend-mobile` — image-generation prompts for UI mockups

## Anthropic official skills
Source: [anthropics/skills](https://github.com/anthropics/skills)

- `frontend-design` — the most-used design skill in the ecosystem: high-impact animations, staggered reveals, scroll-triggered effects, hover states
- `web-artifacts-builder` — polished single-file web apps
- `canvas-design` — visual/poster design on canvas
- `theme-factory` — theme and palette generation
- `algorithmic-art` — generative/creative coding
- `webapp-testing` — browser-based testing of what you build

## Motion & 3D
Sources: [kylezantos/design-motion-principles](https://github.com/kylezantos/design-motion-principles), [CloudAI-X/threejs-skills](https://github.com/CloudAI-X/threejs-skills)

- `design-motion-principles` — motion design fundamentals (easing, timing, choreography)
- `threejs-fundamentals`, `threejs-geometry`, `threejs-materials`, `threejs-textures`, `threejs-lighting`, `threejs-shaders`, `threejs-animation`, `threejs-interaction`, `threejs-loaders`, `threejs-postprocessing` — full Three.js/WebGL suite for 3D and shader effects
